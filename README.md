# Call Translator EN→RU

Первая версия Android-приложения для распознавания английской речи и мгновенного письменного перевода на русский.

## Что умеет
- распознаёт английскую речь через системный Android SpeechRecognizer;
- показывает промежуточный английский текст;
- переводит English → Russian через Google ML Kit;
- после первой загрузки модели перевод ML Kit может работать на устройстве;
- автоматически продолжает слушать после каждой фразы;
- крупный русский текст для чтения во время разговора.

## Важное ограничение обычных телефонных звонков
Android защищает аудио телефонной линии. Обычное стороннее приложение не имеет права напрямую захватывать голос собеседника из cellular call. Во время звонка системное приложение телефона может также занять микрофон, поэтому на части устройств этот прототип получит тишину или ошибку AUDIO.

Это не ошибка программы: это системное ограничение Android. Вне телефонного звонка приложение работает как обычный живой переводчик речи. На звонке можно проверить режим громкой связи, но успех зависит от прошивки устройства.

## Сборка в Android Studio
1. Откройте папку проекта в Android Studio.
2. Дождитесь Gradle Sync.
3. Подключите Android-телефон или создайте APK: Build → Build APK(s).
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск
1. Разрешите микрофон.
2. Подключите интернет для загрузки модели EN→RU.
3. Нажмите «НАЧАТЬ ПЕРЕВОД».

## GitHub Actions
Файл `.github/workflows/build-apk.yml` автоматически собирает debug APK после push в GitHub. Артефакт называется `CallTranslator-debug-apk`.
